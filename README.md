### **ChatB — All-in-one Business OS**

**CRM · POS · WhatsApp Automation · Campaigns · Lead Management**

<a href="https://www.chatb.app/">
  <img src="https://img.shields.io/badge/Landing-chatb.app-6E56FF?style=for-the-badge&logo=vercel&logoColor=white" />
</a>
<a href="https://dashboard.chatb.app/">
  <img src="https://img.shields.io/badge/Dashboard-dashboard.chatb.app-22D3EE?style=for-the-badge&logo=vercel&logoColor=white" />
</a>

</div>

ChatB is a **multi-tenant SaaS platform** where businesses across e-commerce, education, agencies, hospitals, gyms, sports, and travel run their operations from a single dashboard. Each tenant gets CRM, offline + online POS, WhatsApp automation, campaign monitoring, chat, and lead management — plus a website chat widget they can drop onto their own sites to funnel enquiries straight into their inbox.

**My role:** Built the platform end-to-end — multi-tenant data isolation, Redis-backed workers for campaigns and notifications, socket-based chat, WhatsApp Cloud API integration, and the design system used across the entire product.
